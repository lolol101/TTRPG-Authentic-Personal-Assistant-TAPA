# legacy/ — draft implementation

Черновая реализация TAPA (aiogram-бот, LangGraph-роутинг Primary/RAG, Chroma +
e5-large-v2, скрапер Archives of Nethys, PDF-парсер листа персонажа). Написана
до того, как определилась целевая архитектура — см. `../docs/BACKLOG.md`.

Это **референс, не эталон**: код и промпты живут здесь, чтобы их можно было
переиспользовать при сборке `apps/llm-service` (в частности, роутинг
Primary → RAG и структура промптов), но переносить их 1:1 не нужно — новая
структура и правила описаны в `../CLAUDE.md` и `../.claude/rules/`.

Не подключено к новой структуре: собственного `pyproject.toml`/venv здесь
достаточно, чтобы прочитать и прогнать этот код изолированно
(`cd legacy && uv sync --extra bot`), но он не является частью текущей сборки
проекта.
