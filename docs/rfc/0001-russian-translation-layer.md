# 0001. Русский слой корпуса из локализации Foundry

- **Статус:** черновик
- **Дата:** 2026-10-02

## Вопрос

Откуда брать русский текст правил. Интерфейс и вопросы русские, а корпус
английский (`BACKLOG.md`, «Корпус правил», п. 1 «Язык»). Решаем сейчас, потому
что последняя попытка — докачать pf2.ru — упёрлась в блокировку.

## Контекст

**Что есть.** Корпус собирается из паков [foundryvtt/pf2e](https://github.com/foundryvtt/pf2e)
(`packages/pf2e-data/app/foundry.py`): индексируются только записи с
`publication.remaster = true` и лицензией `ORC`/`OGL`. Таких записей 13 443.
Тексты английские. Online-путь под это подстроен: русский вопрос
переписывается в английские поисковые запросы
(`apps/llm-service/app/core/query_rewrite.py`, инструмент
`search_the_rulebooks_in_english` в `tools.py`), а промпт сообщает модели, что
книги на английском (`prompts.py`).

**pf2.ru, 2026-10-02.** Страницы правил отвечают `429` при любом User-Agent.
Вдобавок сайт отдаёт с кодом `200` заглушку «ПОДОЗРИТЕЛЬНАЯ АКТИВНОСТЬ»
вместо правила. Из 2 921 страницы в HTML-кэше 1 200 оказались этой
заглушкой. За несколько часов прогона не скачалось ни одной новой страницы.
Краулер научили ждать отказы и распознавать заглушку (PR #67), но и после
этого остаток в ~10 000 страниц — это минимум ~14 часов при 5 с на страницу,
плюс сколько продлится блокировка. Сколько она длится, предсказать нельзя.

**Русская локализация Foundry — [gnuraco/pf2r](https://gitlab.com/gnuraco/pf2r).**
Официальный пакет `pf2e-ru` на foundryvtt.com, совместим с системой PF2e
8.5.1, последний коммит — 2026-09-27 (`62e8f14`). Переводы лежат в
`data/community/pf2e/packs/pf2e.<пак>.json` в формате Babele:
`entries[<английское имя записи>] = {name, description}`, у журналов —
`pages[<английское имя страницы>] = {name, text}`. Разметка Foundry
(`@UUID`, `@Check`, `@Damage`) сохранена, так что текущий конвертер её
разберёт.

Замеры против нашего чекаута паков (2026-10-02):

| | |
|---|---|
| индексируемых записей с переводом | **13 223 из 13 443 (98 %)** |
| паки ниже 95 % | `bestiary-ability-glossary-srd` — 9 из 47, `equipment` — 96 % |
| описание действительно на русском | 99–100 % (feats, spells, equipment, actions) |
| длина ru / en, медиана | 1.11–1.16 — полный перевод, не пересказ |
| редакция | Remaster: есть Off-Guard («Застигнут врасплох»), нет Flat-Footed |
| журналы | 7 из них, включая GM Screen, переведены постранично |

**Лицензия перевода.** Файл `LICENSE` репозитория: Paizo Community Use Policy
плюс OGL 1.0a. CUP запрещает брать деньги за доступ к контенту. Сейчас
правило проекта (`.claude/rules/ml-system-design.md`, «Данные и лицензии»)
допускает только ORC/OGL.

**Другие кандидаты:**

- [DoctorWater/pf2ru-translation](https://github.com/DoctorWater/pf2ru-translation)
  — та же структура Babele, тексты сообщества pf2.ru. Нет файла лицензии,
  один автор, по README собран ИИ-агентом.
- [pf2e-ru-translation](https://pf2e-ru-translation.readthedocs.io/ru/latest/)
  — `.rst` на GitLab, последнее обновление 2023-08-08. Это Core Rulebook и
  другие книги **до** Remaster. Тот же CUP + OGL. С него начинался
  gnuraco/pf2r.

## Варианты

### A. Русский слой из gnuraco/pf2r поверх английских записей

Конвертер читает английскую запись как сейчас: Remaster, лицензия, книга,
ссылка на коммит берутся из неё. Затем он ищет перевод по `(пак, имя)` и
подставляет русские название и текст. Нет перевода — остаётся английский
текст с `language: "en"`. В метаданные добавляются источник перевода с
коммитом и его лицензия.

- **Хорошо.** 98 % корпуса по-русски за минуты, без сети и банов. Проверки
  редакции и лицензии остаются такими же, как сейчас, потому что метаданные
  берутся из английской записи. Обновление — `git pull` в двух репозиториях.
- **Плохо.** Перевод отстаёт от английского текста на величину своего релиза:
  если Paizo поправит запись, русская версия какое-то время будет старой.
  Ключ — английское имя, поэтому переименованная запись тихо уходит в
  английский фолбэк. Лицензия CUP — см. ниже.
- **Если окажется неверным.** Переиндексация обратно на английский —
  отключить слой конфигом и пересобрать индекс. Часы CPU, код не
  переписывается.

### B. То же, но из DoctorWater/pf2ru-translation

Терминология pf2.ru, которую игроки знают с сайта. Но у репозитория нет
лицензии, а значит, по умолчанию прав на использование нет. Собран
автоматически одним человеком, история короткая. Подменить A на B позже
дешево: формат тот же.

### C. Докачать pf2.ru краулером

Исправленный краулер готов (PR #67). Но срок неизвестен: блокировка
пришла сразу, а сайт явно против обхода. Нужны парсеры под каждый шаблон
страницы, их нет для ancestries, classes и других. Лицензия неизвестна —
то же допущение, что было раньше. Остановлен 2026-10-02 по решению человека.

### D. Машинный перевод английских паков

Свои руки, никакой зависимости от чужого перевода. Но это 13 тыс. записей
через LLM: квота GigaChat, деньги или дни на локальной модели. Термины будут
разъезжаться между записями, и ошибку перевода в правиле никто не заметит
без вычитки. Пометка «машинный перевод» в метаданных обязательна.

### E. Оставить английский корпус

Ничего не делать. Остаётся текущий регресс: цитаты английские, а поиск
каждый раз переписывает вопрос на английский, что стоит лишнего вызова
модели.

## Рекомендация

**A.** Это единственный вариант, где русский текст привязан к той же записи,
по которой уже проверены редакция и лицензия. Остальные либо теряют эту
проверку (B, C), либо стоят несопоставимо дороже (D).

Честно о плохом:

1. **Лицензия.** CUP + OGL — это не «только ORC/OGL». Правило в
   `ml-system-design.md` придётся расширить: «перевод открытого контента под
   CUP допускается, пока продукт бесплатный; в метаданных каждого куска
   стоят `translation_license` и `translation_source`». При монетизации
   решать заново — запросом к Paizo или заменой перевода.
2. **Online-путь придётся переделать.** Сейчас вопрос переписывается в
   английский, промпт говорит про английские книги, golden-набор написан под
   английские цитаты. С русским корпусом:
   - переписывание в английский скорее вредит. Оставить русский запрос,
     возможно, добавив английский как второй — проверять golden-набором;
   - промпт и инструмент `search_the_rulebooks_in_english` поменять;
   - golden-набор перепроверить: ожидаемые цитаты станут русскими.
   Это отдельные задачи с замером, а не часть смены источника.
3. **Индексировать ли английский рядом с русским.** Двойной корпус удвоит
   часы эмбеддингов на CPU (~96 чанков/мин). Предлагаю **только русский с
   английским фолбэком**, но английское имя записи оставить в заголовке
   куска: на него приходят вопросы с английскими терминами, и по нему
   ведёт ссылка на источник.

## Что дальше

Если выбран A, в `BACKLOG.md` уезжают пункты:

1. **Конвертер:** русский слой по `(пак, имя)` с фолбэком на английский,
   поля `language`, `translation_source` (коммит), `translation_license`.
   Тесты на подстановку, фолбэк и журналы.
2. **Сборка в новую коллекцию** (`chroma_collection_prefix`), чтобы сайт не
   простаивал. Это совпадает с уже записанной полной переиндексацией (п. 0
   «Корпус правил»).
3. **Online-путь:** язык поисковых запросов, промпт, инструмент
   переписывания. Замер golden-набором до и после.
4. **Правило лицензий** в `.claude/rules/ml-system-design.md` и строка в
   `DECISIONS.md`.
5. PR #67 (краулер pf2.ru): закрыть или смёржить как починку, которая
   может пригодиться.
