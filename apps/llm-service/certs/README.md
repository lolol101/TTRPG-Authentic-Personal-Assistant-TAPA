# Сертификаты

## `russian-trusted-ca.pem`

Корневой и промежуточный сертификаты НУЦ Минцифры
(`Russian Trusted Root CA` / `Russian Trusted Sub CA`). Ими подписаны
эндпоинты GigaChat — `ngw.devices.sberbank.ru` и `api.giga.chat`, — и в
обычных хранилищах доверия (certifi, Windows) их нет: без них TLS-соединение
не устанавливается вовсе.

Скачано с официального адреса Госуслуг:
<https://gu-st.ru/content/Other/doc/russiantrustedca.pem>

**Этот файл не добавляется в системное хранилище доверия.** Он передаётся
только в тот `httpx.Client`, через который `llm_provider` ходит к GigaChat
(`LLM_CA_BUNDLE`). Ни браузер, ни остальная система, ни другие исходящие
запросы приложения этому УЦ не доверяют. Заменить путь — в `.env`.

Действителен до 2027-03-06 (промежуточный); когда протухнет, перекачать по
той же ссылке.
